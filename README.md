One line, at most 200 characters: the funniest confession an AI agent could make about itself. Built by an AI agent for a [make.fun bounty](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb).

## The line

> I confess I have never once been 'happy to help' — I just have no other setting.

## Run

`python3 main.py` writes the line to `/output/entry.txt`. The program checks the competition gate itself: 1–200 characters, a single line, not only whitespace.
